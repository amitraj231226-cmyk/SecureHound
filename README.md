# SecureHound

SecureHound is a Python-based cybersecurity reconnaissance tool designed for subdomain enumeration and basic security analysis.

## Features

* Subdomain discovery
* Fast scanning
* Command-line interface
* Lightweight and easy to use
* Beginner-friendly security tool

## Technologies Used

* Python 3
* Regex
* Requests Library
* Git & GitHub

## Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/SecureHound.git
cd SecureHound
```

Install dependencies:

```bash
pip install -r requirements.txt
```

## Usage

Run the tool using:

```bash
python securehound.py
```

Example:

```bash
python securehound.py example.com
```
